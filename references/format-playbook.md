# 灵动 Markdown Playbook

格式变化要像写作者临时做的选择，不像一个“随机格式化器”。先看信号，再选动作。

## 先看三个信号

1. **来源**：聊天/会议材料适合保留说话顺序和旁注；正式说明适合只打散一两个段落。
2. **密度**：信息很密时用短段和一个小列表透气；信息很少时不要硬塞表格。
3. **未决程度**：有未决事项才使用 `TODO`、括号旁注或“先放着”；没有就不要制造悬念。

## 动作库

| 动作 | 适合表达 | 例子 |
| --- | --- | --- |
| 单句段 | 强调、转折、犹豫 | `先把这件事做完。` |
| 不对称列表 | 现场记录、不同粒度的待办 | 一项是完整句，下一项只有几个词 |
| 旁注 | 作者自我修正 | `（这句说得有点满）` |
| 引用块 | 原话、暂存判断 | `> 这部分先别动` |
| 临时标题 | 写作者回到主线 | `## 先记一下` |
| 未完成表格 | 比较还没收齐 | 只在确实有比较需求时使用 |

## 选择规则

- 每次最多选 2-4 个动作，优先选择能解释阅读节奏的动作。
- 同一文档不要连续三次使用同一种动作。
- 一个动作如果不能说明“为什么放在这里”，就删掉。
- 标题层级不必完全对称，但文档的主线必须能扫出来。
- 允许保留一处毛边，不能把整页变成装饰。

## 反模板检查

生成后问自己：如果把内容换成另一篇，格式是否还会一模一样？如果会，回到动作库重新选；如果不会，再检查 Markdown 语法和关键事实。
